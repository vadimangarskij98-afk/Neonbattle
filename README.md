# NeonFlow — Управление Wi-Fi и Bluetooth LED-лентой

Современное Android-приложение на Jetpack Compose и Material 3 для управления неоновой LED-лентой по **Wi-Fi** и напрямую по **Bluetooth Low Energy (BLE)** без Wi-Fi.

## Скачать APK на телефон

После отправки проекта в GitHub сборка запускается автоматически:
1. Откройте вкладку **Releases** в этом репозитории (или **Actions → Build NeonFlow APK**).
2. Нажмите на файл **`NeonFlow-v2.1.apk`** — он скачается напрямую на телефон без архива.
3. Откройте скачанный APK и подтвердите установку.

## Основные возможности

- **Wi-Fi + прямое Bluetooth LE (BLE) подключение**:
  - Автопоиск контроллеров в Wi-Fi сети (UDP `48899`) и ручное добавление по IP/порту (**Magic Home / Flux TCP 5577**, **WLED HTTP + UDP DRGB**, **Lotus / ELK TCP & UDP**).
  - Прямое BLE-подключение без Wi-Fi с поддержкой всех 5 протоколов (**Lotus Lantern V6 / MELK**, **ELK-BLEDOM Классика**, **LotusLanternX / BJ_LED**, **Triones / HappyLighting**, **Magic BLE**), мгновенным переключением протокола и проверкой связи (`Красн. / Зел. / Синий`).
- **Цвет и белый свет**:
  - Цветовой круг HSV, температура белого **CCT (2000K–7500K)**, точные RGB-слайдеры, 6 сохраняемых слотов избранного и настройка плавности переходов.
- **Красные и бегущие метровые эффекты**:
  - **Красные**: Алый бархат, Красная комета, Красный лазер, Сердцебиение, Алый + Лёд, Рубиновая лава, Кровавая луна, Рубин и золото.
  - **Бегущие зоны**: Метровый каскад, Прерывистый неон, Бегущий рубин, Встречные потоки, Радужный экспресс, Кибер-поезд, Ледяной маятник.
  - Настройка **длины цветной зоны (0.4 м – 2.5 м)**, мягкости стыков, скорости, направления движения (`→`, `←`, `←•→`, `→•←`) и конструктор своих сцен.
- **Светомузыка и плеер**:
  - 24-полосный анализ спектра микрофона с детектором бита + локальный плеер с синхронизацией света.
- **Таймер сна, расписание и калибровка RGB-пинов**:
  - Плавное затухание перед выключением, расписание по дням недели и удобная калибровка порядка каналов (`RGB`, `GRB`, `BRG` и др.) с тестом `R / G / B`.
